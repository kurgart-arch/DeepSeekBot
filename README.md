# 🧘 Архитектор Судьбы — твой личный наставник в Telegram

Интеллектуальный Telegram-бот на базе DeepSeek, который не даёт готовых ответов, а задаёт глубокие, иногда неудобные вопросы. Он помогает распаковывать старые страхи, менять сценарии, видеть отражения себя в других и двигаться к лёгкой и счастливой жизни.

> *«Я не утешаю, я вывожу из иллюзий».*

## ✨ Особенности

- 🔥 **Честный наставник** — не льстит, не даёт советов, только наводящие вопросы и упражнения.
- 🧠 **Контекстная память** — помнит всю историю диалога в каждом чате (до 20 последних сообщений для точного контекста).
- 🌱 **Индивидуальный подход** — может учитывать дату рождения, психотип и другие личные данные (настраивается).
- 🔮 **Солярные и кармические акценты** — объясняет, почему именно сейчас приходит тот или иной урок.
- 🪞 **Зеркало реальности** — помогает увидеть, что люди вокруг отражают твои собственные убеждения.
- 🏃 **Ритуалы действия** — каждый ответ заканчивается конкретным физическим или письменным упражнением.
- 💬 **Работает 24/7** — всегда на связи в личных сообщениях или по упоминанию в группах.

## 🚀 Быстрый старт

### Для развёртывания (GitHub + Railway)

1. **Сделайте форк** этого репозитория.
2. **Зарегистрируйтесь на [Railway.app](https://railway.app)** (может потребоваться VPN).
3. **Создайте новый проект** → Deploy from GitHub → выберите ваш форк.
4. **Добавьте переменные окружения** (см. ниже).
5. **Нажмите Deploy** — бот запустится через минуту.

### Получение токенов

#### Telegram Bot Token
1. Напишите [@BotFather](https://t.me/BotFather) в Telegram.
2. Отправьте `/newbot` и следуйте инструкциям.
3. Получите токен вида `123456789:ABCdefGHIjklMNOpqrsTUVwxyz`.

#### DeepSeek API Key
1. Зарегистрируйтесь на [platform.deepseek.com](https://platform.deepseek.com).
2. Перейдите в раздел **API Keys** и создайте новый ключ.
3. Пополните баланс (минимальная сумма — $1–2, хватит на месяцы общения).
4. Скопируйте ключ вида `sk-...`.

### Переменные окружения (на Railway)

| Переменная | Описание |
|------------|----------|
| `TELEGRAM_BOT_TOKEN` | Токен вашего Telegram-бота |
| `OPENROUTER_API_KEY` | Ключ DeepSeek (класс называется OpenRouter для совместимости, но использует напрямую DeepSeek) |

## 🎯 Как использовать бота

### В личных сообщениях
Просто напишите боту что угодно — он ответит всегда, используя контекст всего диалога.

### В группах
Упомяните бота по имени (например, `@nastanik_dushi_bot`) или напишите «Архитектор» — он отреагирует только на обращение.

### Команды
- `/start` — приветствие и краткое описание.
- `/help` — подробная справка.
- `/clear_memory` — очистить память чата (начать диалог заново).

## 🧠 Как работает «Архитектор»

1. **Системный промпт** — жёсткая инструкция: не давать советов, только вопросы и упражнения.
2. **Контекст** — берёт последние 20 сообщений из памяти, чтобы видеть динамику.
3. **Генерация** — отправляет запрос к DeepSeek (модель `deepseek-chat` или `deepseek-reasoner`).
4. **Ответ** — возвращается пользователю, сохраняется в памяти для продолжения.

🔧 Настройка личности бота

В файле bot_config.py есть переменная SYSTEM_PROMPT — её можно редактировать, чтобы менять стиль общения, добавлять новые правила или учитывать конкретные данные пользователя.

Пример расширения:
# Добавить персональные данные
if user_data.get(chat_id):
    system_prompt += f"\nДата рождения пользователя: {user_data[chat_id]['birth_date']}"
